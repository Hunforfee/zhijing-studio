从商品展示到家纺内容创作

2026-10-16。以下方案是本站基于公开商品分类与资料组织方式设计的内容工作流，不宣称复刻商家视频，也不将其他商家的规格与卖点移植到用户商品。

研究来源与访问边界

  • 找家纺公开分类：可读取四件套、单品、床笠、枕芯、冬被、凉席等类目及工艺、材料命名。由此按产品结构分配内容重点，不将所有商品统写成床品全景。
  • 找家纺：立体雕花双层花边四件套：搜索索引可核实商品标题、床单/床笠规格区分及视频入口。直接访问受限制，未完整播放商家成片；不宣称观察过具体镜头顺序。
  • 找源头官网：本次访问返回站点访问保护页面，未取得完整商品和视频内容。不绕过保护，不据此编造其内容规律。
  • 智谱 CogVideoX-3 官方文档：支持图片输入、5/10秒生成与异步查询。本站将每个独立分镜映射为一次视频生成，再在本机统一剪辑和烧录字幕。

内容结构（本站创作方案）

方向叙事主线画面任务
生活方式故事一天的情绪 → 日常小动作 → 属于自己的休息时刻开场提出生活切口，中间用手部整理或环境事件推进，收尾回应情绪。
工艺解说提出观察问题 → 可见结构证据 → 回到整体搭配指认实物可见边缘、缝线与部件连接，工艺只作用于对应部件。
选购指南自己的房间与需求 → 花型及铺放观察 → 选择思路提供观察方法，未知规格不代填，不虚构实验、指标与效果。
换季焕新换一种生活节奏 → 整理与搭配过程 → 日常新期待保持同款商品，用生活动作与配色关系表达换季，不编造适温与季节功效。
新品种草有记忆点的开场 → 具体细节承接 → 生活情境收束用真实花色和可见工艺建立记忆，不虚构销量、价格、材质与认证。

实际执行

用户添加最多6张同款照片，填写创作要求和已确认商品资料，选择15/20/30秒。AI通过当前图片识图服务分析全部照片，创作3/4/6镜脚本；也可从明确标记的本地模板开始。主题、故事主线、逐镜内容、动作、字幕、口播文稿和素材归属均可编辑。口播稿是文字导出，不代表已经合成配音。

确认脚本后，服务器校验结构、时长及素材索引，逐镜调用智谱视频接口。每镜独立保存上游任务编号及原始MP4；异常停止后续提交并保留已完成镜头。继续获取时复用已有任务与分镜，不重复生成成功的镜头；提交状态不明确时禁止自动重提。全部完成后，FFmpeg归一化尺寸、帧率、音轨和时长，按脚本顺序剪辑并烧录中文字幕，输出MP4及SRT。各分镜可单独预览下载。

商品一致性

保持原花色、图案比例、A/B面、部件数量、层数、可见工艺与房间连贯。四件套按部件追踪外沿；夏被不变厚冬被；竹席条片不揉成布；床笠不变垂边床单；枕芯不凭外壳猜填充；薄旅行睡袋不变露营睡袋。缺少资料的成分、支数、克重、尺寸、认证、抗菌、母婴、疗效、销量和洗护条件均不据图猜测。

验证

测试使用模拟策划与视频服务，不调用付费生成。检查最终供应商请求逐镜不同、素材匹配、后续停止、重启恢复、原任务重取与已完成分镜复用；使用真实FFmpeg解码确认15秒450帧、中文字幕及AAC轨道，并通过浏览器检查20秒成片实际播放与五种窗口尺寸。测试证明执行与剪辑链路，不代表已经验证实际模型对花色、手部动作及跨镜连续性的生成质量。

最新更新：仅花型参考的创意场景（覆盖旧的沿用原场景执行方式）
