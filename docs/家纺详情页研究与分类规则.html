长页结构（本站设计方案）

6张3:4竖版独立切片，主视觉 → 花型与质感 → 部件与工艺 → 铺用与搭配 → 选配指南 → 日常照护与收尾。等宽从上到下拼接，章节完整落在同一切片内。统一底色、字体层级和左右安全边距，图为主、文字为辅。按模块改图，不把单张短图拉长。

自然预览6段；可导出拼接长图、切片ZIP；二次编辑在右侧，可改全部或指定一段。逐段生成占6次图片请求，界面显示真实完成数；停止或失败保留已完成段。没有具体款式元数据时保持自动识别，不强行默认为冬被、薄垫等。
