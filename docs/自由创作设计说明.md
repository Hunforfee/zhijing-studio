# 自由创作：从现有图片继续设计

自由创作放在左侧导航的“视频”下方，点击后进入独立工作区。左侧是大图、原图对比与版本，右侧是创作设置，与现有图片、详情和视频区的使用习惯保持一致。

设计参考了 [Loom42](https://loom42.com/home) 的局部编辑与虚拟影棚，以及[纺知云](https://fzyaigc.com/) 的场景生成、营销主图等入口。首版聚焦“拿已有图片继续改”，不把花型设计、详情排版等不同流程堆在一个界面中；上述站点仅用于功能研究，没有复制其图片、品牌或代码。

## 已实现的六种创作方式

| 方式 | 适合做什么 | 示例要求 |
| --- | --- | --- |
| 自由修改 | 自己描述具体修改 | 把床头画换成简洁的植物装饰画，其他不变 |
| 更换场景 | 换房间、背景或影棚 | 换成原木卧室，保留床品花型、配色和宽边 |
| 调整光影 | 自然光、色温、画面层次 | 改成窗边柔和侧光，避免过曝和偏色 |
| 清理画面 | 移除指定杂物 | 只移除床头柜上的多余物件，背景自然补全 |
| 修饰细节 | 优化可见褶皱、边缘、织纹 | 让床沿褶皱自然，保留缝线和原有结构 |
| 延展构图 | 调整画面比例，增加空间 | 延展为 3:4 竖图，完整展示产品，墙面留白 |

## 建议这样使用

1. 上传一张 JPG、PNG 或 WebP，也可以从已有图片作品导入。原图保留在独立创作记录中。
   为保证上传和编辑稳定，大图会等比例适配至最长边 2048 像素；界面显示本次编辑底图的尺寸，框外像素保留以该底图为准。
2. 选择创作方式，再写清“改哪里、改成什么、哪些保持不变”。方式卡片带有可编辑的示例，另有晨光卧室、干净白底、清理杂物三个快捷灵感。
3. 若只想改一个位置，点击大图上方“框选修改”，拖动选择区域。此时比例自动跟随当前图片，框外像素从当前编辑底图保留；框内与外部的衔接做柔和处理。
4. 需要参考空间或光线时添加一张辅助参考图，在文字中说明使用哪一方面。系统仍以当前图片为主图。
5. 默认勾选保留花型与配色、保留结构与工艺。若明确要求换色或改工艺，应在描述中写清范围；未请求的部分仍优先保留。
6. 默认比例 3:4，可改为 1:1、4:3 或跟随原图。延展构图使用整体编辑，需要先取消框选。
7. 点击“生成修改图”后使用当前图片服务计费。新结果另存为 V1、V2 等版本；可对比最初原图、下载当前图片，或点击任意旧版本继续编辑，分支版本均保留。

首次可以尝试一句范围很清楚的要求：“只将房间改成温暖原木风，保留床品花型、宽边、枕套数量和原色，不添加装饰抱枕。”局部清理时先把杂物周围稍多一点的背景一起框入，更容易形成自然衔接。

## 为什么这样安排

- 输入与预览始终在同一工作区，避免上传、编辑和历史之间反复跳转。
- 简单任务用预设帮助表达；复杂想法仍通过自由文字和参考图完成。
- 首版框选编辑通过实际像素合成保留框外区域。其作用范围可检查；框内具体语义与生成质量仍取决于所选图像服务，不能据此承诺花型绝对无变化。
- 一次只生成一个编辑版本，先确认方向再继续；与图片拍摄和详情编辑共用 FIFO 队列，保留停止功能，不自动重试付费请求。
- 上传仅保存素材，只有主动点击生成才提交外部图像编辑。原图、参考内容与生成图片放在 `generated/` 中，继续排除在 Git 之外。

## 下一阶段建议

优先根据真实使用反馈增加画笔涂抹与橡皮擦、区域微调、同一要求生成多个可比较方案；之后再考虑系列配色与营销文字排版。高清放大、无缝花型提取应使用适合的专门流程验证效果后再提供入口，避免把普通提示词编辑包装成已保证的能力。

## 部署与验证

拉取更新后执行 `npm ci`，再重启服务。`pngjs` 用于验证 PNG 和合成框选区域。参考图编辑沿用现有 Sub2API、OpenAI 或兼容服务；只支持参考重绘的服务会明确提示切换接口。

运行 `npm run test:free` 验证编辑、框外像素、队列、停止、版本与来源限制。`free-creation-ui-test.mjs` 使用本地浏览器和模拟供应商，覆盖上传、参考图、框选、对比、记录、刷新恢复与五种窗口宽度。测试不调用付费生成。

本次针对性回归共 36 项通过，自由创作和原详情长图也通过真实浏览器验证。扩展运行的两个旧测试文件仍有 12 项失败：旧图库模拟 DOM 缺少 `document.body`，参考图测试还使用旧标题和旧提示格式。模拟 DOM 问题已在修改前的 `356052c` 基线复现，相关图库、参考图实现和旧测试本次均未改动。尚未为功能验收调用真实付费接口，实际模型效果需在用户主动生成后评估。
