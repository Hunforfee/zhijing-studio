# 加枕芯后的角度示例：资源与编辑提示词

用途：更新网站被芯、床单 / 床笠的角度参考图片。使用内置 image_gen 编辑已有图集，保留产品、12 个机位、4×3 网格、光线和质感。在床头加入一对纯白枕芯，自然或整齐摆放。特写的枕芯可自然处于取景框外，避免为展示枕芯改变选定机位。

生成方式：内置图片生成工具；不用网站保存的中转 API Key。
