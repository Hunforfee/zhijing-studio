# 织景工作台

家纺产品图片、商品详情页与视频创作工作台。

首页采用舒展的家纺品牌排版，以大幅氛围图与留白展示生活灵感；下方九个创作入口进入 AI 工具：场景创建、花型设计、高清修复、花型提取、系列配色、连续接缝、灵感搭配、上架适配及商品文案。AI 先给候选，用户确认后应用并手动精修；设计室支持可编辑 AI 排花、独立图层、工程保存和带实际 DPI 的 PNG / 可编辑 SVG。只有主动点击 AI 按钮才调用当前服务；本机精修和导出独立可用。用法、边界与公开参考见[家纺灵感工具箱使用说明](docs/家纺灵感工具箱使用说明.md)。

`/scenes` 新增 AI 场景创建：文字或参考图生成候选，命名保存后可在原工作台“我的场景”中选用；仅作为环境参考，保留产品 A/B 花型及拍摄角度。自建场景随服务端数据持久保存，不入 Git。

花型上传只在浏览器内加载和管理，不再自动分析或改动工艺、面料设置；A/B 主图及补充图会在主动开始生图时一并提供给模型。

网站根地址现在显示织景首页；点击“进入工作台”进入原有完整功能页面 `/workspace`。首页提供图片、详情、视频和自由创作的快捷入口，工作台左侧顶部品牌图标可返回首页。旧 `/index.html` 地址仍可直接访问工作台。首页只展示已有内置素材，不读取用户作品、不上传图片、不调用生成接口。

左侧“自由创作”支持上传或导入现有图片，自由修改、更换场景、调整光影、清理画面、修饰细节和延展构图。提供框选修改、原图对比、辅助参考图和独立版本记录；使用已有图片接口，上传和生成素材继续留在 `generated/`。设计与使用建议见[自由创作设计说明](docs/自由创作设计说明.md)。

## 本仓库的同步范围

本仓库同步项目源码、页面样式、文本提示规则、测试、运行说明，以及网站自带的面料、场景、机位、工艺和褶皱参考素材。

按项目所有者最新要求，内置参考素材通过 `tools/builtin-assets.json` 清单和 `.gitignore` 中的逐文件例外恢复到 Git。**用户上传图片、生成图片和视频仍不上传**；`generated/`、`output/`、`exports/`、`assets-source/`、旧版素材备份、API 密钥明文、DPAPI 配置、日志、本地依赖和历史备份继续排除。`deploy/` 中保存加密的服务备份和不含密钥的设置清单。

新部署可直接加载内置的面料缩略图与高清参考、场景照片、产品机位图、工艺示意图和默认褶皱参考。用户图片与视频历史仍只保存在原电脑。素材清单记录文件大小和 SHA-256，可用 `node tools/check-builtin-assets.mjs --http` 检查文件及网站资源响应，无需调用生成接口。

## 运行

1. 安装 Node.js 22 或更新版本。
   首次部署运行 `npm ci` 安装视频剪辑依赖，再运行 `npm run check:video` 检查。
2. 在项目目录运行 `npm start`。
3. 打开 `http://127.0.0.1:4173`，点击“进入工作台”，在左侧“设置”中配置图片服务。
4. 内置素材已随代码提供，无需另行复制；不要将用户上传和生成记录当成内置素材提交。

本地运行配置按 Windows 当前用户加密保存在 `.share/`，不随 Git 同步。另有不含明文密钥的云端加密配置备份，详见 [云端部署说明](deploy/README.md)；部署时需由服务器环境变量注入 GitHub Secret `ZHJ_DEPLOYMENT_KEY`。Sub2API 地址需要能被部署服务器访问；本机回环地址仅适用于中转运行在同一台服务器的情况，可通过网站设置或服务器环境变量配置。

## 视频处理

- 稳定运镜在本地使用 FFmpeg，不需要视频生成 API。
- AI 动态使用单独配置的视频服务。
- 分层景深目前是独立试片渲染器，采用人工标注区域，并未替换默认工作流。

FFmpeg、OpenCV 和 Python 环境说明见 [视频剪辑组件说明](tools/视频剪辑组件说明.txt)。这些本机组件不提交到仓库。
