# 织景工作台

家纺产品图片、商品详情页与视频创作工作台。

## 本仓库的同步范围

本仓库仅同步项目源码、页面样式、文本提示规则、SVG 图标、测试与运行说明。

按项目所有者要求，**不上传本机已有或生成的图片、视频**，包括 `generated/`、`output/`、`exports/`、原始素材和 `dist/assets/` 中的位图。API 密钥的明文、DPAPI 配置、日志、本地依赖和历史备份也不提交；`deploy/` 中仅保存加密的服务备份和不含密钥的设置清单。

所以此仓库是代码备份，不包含完整素材库。源码中的资源路径保留；在另一台电脑运行时，角度、面料、场景等预览图片需要从原电脑另行复制到对应位置。图片与视频历史仍保存在原电脑，并未删除。

## 运行

1. 安装 Node.js 22 或更新版本。
2. 在项目目录运行 `npm start`。
3. 打开 `http://127.0.0.1:4173`，在网站中配置图片服务。
4. 如需原有素材库，从原电脑恢复 `dist/assets/` 下的本地图片；不要将用户生成记录当成代码资源提交。

本地运行配置按 Windows 当前用户加密保存在 `.share/`，不随 Git 同步。另有不含明文密钥的云端加密配置备份，详见 [云端部署说明](deploy/README.md)；部署时需由服务器环境变量注入 GitHub Secret `ZHJ_DEPLOYMENT_KEY`。当前主用图片服务依赖本地 Sub2API 中转，也需在云端部署或替换为服务器可访问的地址。

## 视频处理

- 稳定运镜在本地使用 FFmpeg，不需要视频生成 API。
- AI 动态使用单独配置的视频服务。
- 分层景深目前是独立试片渲染器，采用人工标注区域，并未替换默认工作流。

FFmpeg、OpenCV 和 Python 环境说明见 [视频剪辑组件说明](tools/视频剪辑组件说明.txt)。这些本机组件不提交到仓库。

## 检查

```sh
npm run check
node --test video-service-test.mjs video-story-planner-test.mjs
```

浏览器、图像与视频测试可能需要原电脑的预览素材及本地依赖。不要使用真实付费生成接口作回归测试。
