# 织景工作台

家纺产品图片、商品详情页与视频创作工作台。

首页采用舒展的家纺品牌排版，以大幅氛围图与留白展示生活灵感；下方九个创作入口进入 AI 工具：场景创建、花型设计、高清修复、花型提取、系列配色、连续接缝、灵感搭配、上架适配及商品文案。AI 先给候选，用户确认后应用并手动精修；设计室支持可编辑 AI 排花、独立图层、工程保存和带实际 DPI 的 PNG / 可编辑 SVG。只有主动点击 AI 按钮才调用当前服务；本机精修和导出独立可用。用法、边界与公开参考见[家纺灵感工具箱使用说明](docs/家纺灵感工具箱使用说明.md)。

`/scenes` 新增 AI 场景创建：文字或参考图生成候选，命名保存后可在原工作台“我的场景”中选用；仅作为环境参考，保留产品 A/B 花型及拍摄角度。自建场景随服务端数据持久保存，不入 Git。

花型上传只在浏览器内加载和管理，不再自动分析或改动工艺、面料设置；A/B 主图及补充图会在主动开始生图时一并提供给模型。

网站根地址现在显示织景首页；点击“进入工作台”进入原有完整功能页面 `/workspace`。首页提供图片、详情、视频和自由创作的快捷入口，工作台左侧顶部品牌图标可返回首页。旧 `/index.html` 地址仍可直接访问工作台。首页只展示已有内置素材，不读取用户作品、不上传图片、不调用生成接口。

左侧“自由创作”支持上传或导入现有图片，自由修改、更换场景、调整光影、清理画面、修饰细节和延展构图。提供框选修改、原图对比、辅助参考图和独立版本记录；使用已有图片接口，上传和生成素材继续留在 `generated/`。设计与使用建议见[自由创作设计说明](docs/自由创作设计说明.md)。

## 工具箱 C 布局

`/tools` 已应用确认的 C 方案：顶部切换工具，左侧添加素材与描述方向，中间预览当前作品，右侧查看真实 AI 候选和精修设置。标题、三步导航与保存/导出合并为紧凑工具栏，深灰文字、墨绿操作与白色面板提高对比度；手机自动换行。三步导航可定位相应操作；采用候选后展开精修，仍可撤回。顶部导出、图库保存与下方原有操作共用当前工具结果，跨工具继续处理保留原像素与印花参数。窄屏自动纵向排列，问号仍支持悬停或触屏点击。

`node textile-workflow-ui-test.mjs` 使用临时模拟服务，检查七个工具、六种窗口、候选采用、顶部原尺寸导出和图库保存；不会调用付费 AI。

## 家纺电商工具箱

`/ecommerce` 提供营销排版、SKU 规格图、尺寸导购图与商品一致性检查，首页及原工作台左侧“电商”可进入。商品原图、资料、最多 24 个规格和 AI 候选保存在本机 IndexedDB，四项工具共用；上传、修改与恢复不会自动调用 AI。统一通过已有 Sub2API 识图/文本配置进行策划，候选确认后应用，可继续修改或撤回；失败不自动重试。

营销图使用原始商品图与本机独立文字排版，价格和尺寸只来自已填资料；SKU 必须确认图片对应，尺寸示意不能通过照片测量。默认 3:4，可导出 PNG、按规格打包 ZIP 并附 CSV，支持规格模板导入/导出及保存成品到图库。检查结果是待人工确认的疑点，可定位图片、记录确认需改/已核实无误并下载报告，不是品质检测或认证。现有拍摄、详情、文案及适配通过原入口衔接。

`node --test ecommerce-test.mjs textile-ai-planner-test.mjs` 和 `node ecommerce-ui-test.mjs` 使用临时模拟服务，覆盖事实拦截、SKU 映射、CSV、候选确认/撤回、批量打包、尺寸图、报告、草稿恢复及七种屏宽；不调用付费 AI。当前代码已同步 Git，未主动部署到线上；用户图片与本机草稿仍不入 Git。

## 花型流转与我的素材库

工具箱的“继续处理”按当前结果的原始像素传给下一个工具，画布预览仅缩放显示；PNG 的花回厘米与 DPI 信息会随支持的处理流程传递。提取裁切、连续单元、放大与上架适配仍按用户明确选择的输出尺寸处理；AI 生成和修改可能重绘图片，不承诺与原稿像素相同。

“我的花型 / 商品库”入口为 `/library`，可上传、搜索、按系列筛选、修改资料和下载原稿。每张 PNG 最多 32 MiB、单边 16000 像素、总计 6400 万像素；原始 PNG 字节独立保存，缩略图另行生成。JPG / WebP 入库先在浏览器转为原尺寸 PNG。可保存名称、款号、系列、标签、说明与印花尺寸；商品可配套保存 A/B 主图。图片、元数据保存在 `generated/asset-library/`，继续排除在 Git 之外，不会自动分析或调用 AI。

拍摄区可从素材库选“用作 A 面”“用作 B 面”或“应用整款”。单面选用保留另一面与当前产品设置；整款恢复保存的主 A/B 与当前产品菜单工艺、面料库选项。保存整款不包含多图补充素材、上传的质感参考、场景、镜头和智能角度数量。异步读取期间若花型或将被恢复的设置已变化，本次应用取消，避免覆盖用户后选内容；从素材库链接进入工作台时，仅从本机上次花型补齐缺失的另一面。

保存须用户确认后提交，重复保存请求沿用编号以避免重复记录；分享访客只能访问本邀请保存的条目与原图。删除为服务端软删除，不会因旧保存请求重试而自动恢复。本批功能目前仅在本地验证，尚未提交、推送或部署。

界面说明可通过模块标题旁的“？”在电脑端悬停查看，移入浮层可继续阅读；手机保留点击，也支持键盘与弹窗内使用；计费、进度、错误及删除确认继续直接显示。长输入示例可在对应帮助中查阅，不修改生成参数或后台提示词。检查可运行 `node context-help-ui-test.mjs`，使用本机临时模拟服务，不调用付费 AI。

## 本仓库的同步范围

本仓库同步项目源码、页面样式、文本提示规则、测试、运行说明，以及网站自带的面料、场景、机位、工艺和褶皱参考素材。

按项目所有者最新要求，内置参考素材通过 `tools/builtin-assets.json` 清单和 `.gitignore` 中的逐文件例外恢复到 Git。**用户上传图片、生成图片和视频仍不上传**；`generated/`、`output/`、`exports/`、`assets-source/`、旧版素材备份、API 密钥明文、DPAPI 配置、日志、本地依赖和历史备份继续排除。`deploy/` 中保存加密的服务备份和不含密钥的设置清单。

新部署可直接加载内置的面料缩略图与高清参考、场景照片、产品机位图、工艺示意图和默认褶皱参考。用户图片与视频历史仍只保存在原电脑。素材清单记录文件大小和 SHA-256，可用 `node tools/check-builtin-assets.mjs --http` 检查文件及网站资源响应，无需调用生成接口。

## 运行

1. 安装 Node.js 22 或更新版本。
   首次部署运行 `npm ci` 安装视频剪辑依赖，再运行 `npm run check:video` 检查。
2. 在项目目录运行 `npm start`。
3. 打开 `http://127.0.0.1:4173`，点击“进入工作台”，在左侧“设置”中配置图片服务。
4. 内置素材已随代码提供，无需另行复制；不要将用户上传和生成记录当成内置素材提交。

本地运行配置按 Windows 当前用户加密保存在 `.share/`，不随 Git 同步。另有不含明文密钥的云端加密配置备份，详见 [云端部署说明](deploy/README.md)；部署时需由服务器环境变量注入 GitHub Secret `ZHJ_DEPLOYMENT_KEY`。Sub2API 地址需要能被部署服务器访问；本机回环地址仅适用于中转运行在同一台服务器的情况，可通过网站设置或服务器环境变量配置。

## 视频处理

- 稳定运镜在本地使用 FFmpeg，不需要视频生成 API。
- AI 动态使用单独配置的视频服务。
- 分层景深目前是独立试片渲染器，采用人工标注区域，并未替换默认工作流。

FFmpeg、OpenCV 和 Python 环境说明见 [视频剪辑组件说明](tools/视频剪辑组件说明.txt)。这些本机组件不提交到仓库。

## 检查

```sh
npm run check
npm run test:library
node --test request-source-test.mjs share-test.mjs scene-creation-test.mjs pattern-materials-test.mjs
node --test video-service-test.mjs video-story-planner-test.mjs
```

`npm run test:library` 覆盖原 PNG / A/B 字节、尺寸与印花元数据、资料编辑、幂等保存、软删除、重启恢复及双邀请隔离。`node asset-library-ui-test.mjs` 和 `node workspace-library-ui-test.mjs` 使用本机浏览器及模拟服务检查图库页面、工具/设计室入库、拍摄单 A/B 与整款应用；浏览器检查需本地 Playwright 与 Edge。来源、分享、场景与花型补充素材回归同样使用模拟接口，不调用付费生成。

内置预览素材已随仓库提供。部分浏览器、图像与视频测试仍需本地依赖。不要使用真实付费生成接口作回归测试。
